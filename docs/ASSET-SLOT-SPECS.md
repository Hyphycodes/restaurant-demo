# Media slot requirements

- Hero: landscape, 1800 × 1200, visually clear at phone and desktop widths.
- Editorial dining and food: 900–1200 pixels across, local WebP, descriptive alt text.
- Wordmark: 1000 × 260, warm cream background, readable at navigation size.
- Event posters: 900 × 1125; no baked-in dates. Accessible HTML supplies dates and prices.
- Responsive event backgrounds: 1600 × 900 and 640 × 360 wide crops; 900 × 1125 and 448 × 560 upright crops.
- Maximum registered image budget: 500 KB. All shipped images fit within it.

Keep media in the semantic registry. The public site and administrative media library resolve the same records. Uploads are disabled in the portfolio demo, while descriptions, focal points and swaps between existing local assets remain available in each visitor's temporary workspace.
